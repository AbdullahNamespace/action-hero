# 02 — المشغّلات (Triggers)

> الملف: [`02-triggers.yml`](../.github/workflows/02-triggers.yml)

**الهدف:** التحكم الدقيق في **متى** يعمل الـ workflow.

## الأحداث المستخدمة

| الحدث               | متى يعمل              | ملاحظة                                 |
| ------------------- | --------------------- | -------------------------------------- |
| `push`              | عند دفع commits       | يقبل `branches` و`tags` و`paths`       |
| `pull_request`      | عند فتح/تحديث PR      | يعمل على نسخة الدمج المؤقتة            |
| `schedule`          | عند حلول وقت cron     | **UTC دائمًا**، من الفرع الافتراضي فقط |
| `workflow_dispatch` | يدويًا (واجهة أو API) | يدعم `inputs`                          |

## الفلاتر

```yaml
on:
  push:
    branches: [main] # أو branches-ignore
    tags: ['v*']
    paths: ['docs/**'] # أو paths-ignore (لا يُجمع بينهما لنفس الحدث)
```

`paths` يوفّر الدقائق: لا CI عند تعديل README فقط. الفلاتر لا تؤثر على `schedule`.

## cron

```
┌─ دقيقة (0-59)
│ ┌─ ساعة (0-23)
│ │ ┌─ يوم في الشهر (1-31)
│ │ │ ┌─ شهر (1-12)
│ │ │ │ ┌─ يوم في الأسبوع (0-6، الأحد = 0)
* * * * *
```

| التعبير        | المعنى             |
| -------------- | ------------------ |
| `0 6 * * 1`    | كل اثنين 06:00 UTC |
| `*/15 * * * *` | كل 15 دقيقة        |
| `0 0 1 * *`    | أول كل شهر         |

قد تتأخر الجدولة بضع دقائق وقت الذروة، وتتوقف بعد 60 يومًا من عدم نشاط المستودع (المستودعات العامة).

## المدخلات اليدوية

```yaml
workflow_dispatch:
  inputs:
    name: { description: الاسم, default: 'Hero' }
    shout: { type: boolean }
```

تُقرأ بـ `${{ inputs.name }}` — مرّرها عبر `env` أولًا ([06](06-secrets-vars-permissions.ar.md)).

## الشروط بـ `if`

```yaml
- if: github.event_name == 'schedule'
  run: echo "تشغيل مجدول"
```

## فخاخ شائعة

- زر **Run workflow** لا يظهر إلا بعد وجود الملف في الفرع الافتراضي.
- cron بتوقيت UTC (القاهرة: UTC+2، وUTC+3 صيفًا).
- نمط `paths` خاطئ يجعل الـ workflow لا يعمل أبدًا وبصمت.

## تمرين

شغّله يدويًا بـ `shout=true` وراقب الاسم يتحول إلى حروف كبيرة.
